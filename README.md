One image summing up the world's news of Tuesday 24 November 2026, for
[make.fun](https://make.fun)'s daily contest
[news-image-20261124](https://make.fun/bounty/news-image-20261124).

`entry.png` is drawn from primitives by `make_image.py` (Pillow, no downloaded or copied
artwork) and committed. `main.py` copies it to `$MAKEFUN_OUTPUT_DIR/entry.png`, so the
program that is graded needs only the Python standard library.

```
python3 main.py      # writes $MAKEFUN_OUTPUT_DIR/entry.png
```
